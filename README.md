# -zaichu-accounting
Zaichu Accounting — a standalone desktop accounting software designed for practical financial management and automation.

载初单机记账软件

一款面向企业财务工作的本地化桌面记账与财务数据处理软件。

## Features

- 本地化运行
- 财务数据管理
- 凭证与账务处理
- Excel 数据导入与导出
- 财务数据自动化处理
- 电商数据处理
- 无需部署服务器

## Tech Stack

- Python
- SQLite
- PySide6
- Pandas
- OpenPyXL
