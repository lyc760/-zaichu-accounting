# 载初单机记账软件 (Zaichu Accounting)

> 一款面向中小企业和个人商户的**本地化单机记账软件**
> 无需联网、无需服务器、数据完全掌握在自己手里

---

## 📖 项目简介

载初单机记账软件是一款**完全离线运行**的桌面记账工具，专为中小企业、个体户、自由职业者设计。

**核心特点：**
- 🔒 **数据本地化** — 所有数据存储在本地 SQLite 数据库，不上传任何服务器
- ⚡ **开箱即用** — 打包成单个文件夹，拷贝即用，无需安装
- 🎨 **现代化界面** — 基于 PySide6 + Windows 11 Fluent Design 风格
- 📊 **完整账务** — 科目、凭证、报表、工资一站式
- 🔐 **授权保护** — 机器码绑定 + HMAC 签名激活，支持试用与续费
- 💾 **自动备份** — 每次修改自动生成备份，可一键还原

---

## ✨ 功能列表

### 核心功能

| 模块 | 功能 |
|---|---|
| **科目管理** | 多级科目树、增删改查、导入导出 CSV、期初余额 |
| **凭证管理** | 借贷分录录入、实时平衡校验、锁定保护、附件管理 |
| **科目余额表** | 按期间查看各科目借贷发生额、年累计、期末余额 |
| **资产负债表** | 自动计算资产 / 负债 / 权益，实时校验平衡 |
| **利润表** | 本月 / 本季度 / 本年累计，标准会计格式 |
| **工资管理** | 员工花名册、工资表、代扣社保/公积金/个税、自动生成凭证 |
| **日志与备份** | 操作日志、自动备份、一键还原 |
| **数据导出** | CSV 导出 + HTML 电子凭证册（含附件内嵌） |

### 特色功能

- 🔐 **机器码授权** — 一台机器一个激活码，支持 365 天 / 永久两种
- 🕒 **时间保护** — 防止通过修改系统时间延长试用
- 📎 **附件嵌入** — 图片 / PDF / Excel / CSV 可内嵌到电子凭证册
- 🎯 **锁定保护** — 设置锁定日期后，之前凭证不可修改
- 💰 **借贷平衡** — 实时显示借方/贷方合计与差额
- 👥 **员工生命周期** — 入职 / 离职月份自动过滤工资表

## 🚀 快速开始

### 直接使用打包版（推荐普通用户）

1. 解压 `载初记账软件.zip` 到任意文件夹（**建议 D 盘新建文件夹，不要放桌面**）
2. 双击 `载初记账软件.exe`
3. 首次启动会弹出激活窗口：
   - 点"**复制机器码**"
   - 发给店铺获取激活码
   - 粘贴激活码 → 点"激活"
4. 激活成功后即可正常使用
